# AIO Life 浏览器助手

连接 AIO Life 的 Manifest V3 浏览器扩展，支持 B 站视频标记与分 P 进度同步、豆瓣书籍／影视采集，以及京东／淘宝订单商品录入。扩展直接加载源码运行，无需构建。

## 功能范围

| 来源 | 操作 | 写入 AIO Life |
| --- | --- | --- |
| B 站视频详情 | 手动标记；进入视频或切换分 P 时同步已标记视频的进度 | 视频记录 |
| 豆瓣书籍／影视详情 | 手动采集、预览查重、确认保存 | 阅读／观影记录 |
| 豆瓣电影／剧集详情 | 可选自动同步“想看”“看过”和取消收藏 | 观影记录 |
| 京东／淘宝订单详情 | 核对商品后逐件选择归属，保存后可继续编辑 | 设备／衣物 |

购物采集不保存订单正文、采购历史，不创建支出；订阅采集和历史批量导入不在当前范围。页面解析依赖站点 DOM，缺失字段需要人工补齐。

## 安装与连接

1. 准备支持当前 `/api/b-video/*`、`/api/capture/*`、文件上传和设备／衣柜接口的 [AIO Life 后端](https://github.com/lys1313013/aio-life-server)。现有数据库需要按后端升级说明核对采集来源字段；当前购物来源查重使用 [2026-10-28 增量脚本](https://github.com/lys1313013/aio-life-server/blob/main/sql/migrations/2026-10-28_01_asset_purchase_source.sql)，不能仅升级扩展后直接使用旧表结构。
2. 克隆本仓库，在 Chrome 的 `chrome://extensions` 中启用开发者模式，点击“加载已解压的扩展程序”，选择包含 [manifest.json](manifest.json) 的仓库根目录。其他 Chromium 浏览器使用对应扩展管理页。仅使用扩展时不需要 `npm install`。
3. 点击工具栏中的 AIO Life，打开“连接设置”，填写带 `/api` 的服务地址和账号的 Authorization Token，保存并授权该服务域名。默认地址为 `https://aiolife.top/api`；本地开发可使用 `http://127.0.0.1:45678/api`。Token 按原值发送，留空保留原配置，清除按钮移除已保存 Token。
4. 打开受支持的详情页使用对应入口。更新本地源码后，在扩展管理页点击“重新加载”，再刷新相关网站页面；录入页未保存的内容需先处理。

若采集时提示插件页面与后台版本不一致，在 `chrome://extensions` 找到 AIO Life 并点击“重新加载”，再回到来源页面重新采集。只刷新录入页不会更新扩展后台；旧录入链接不能恢复已移除的本地草稿。

## 日常使用

### B 站视频

在工具栏弹窗或视频页“更多”菜单中选择待看、已看、学习中、暂停，对应 `not_started`、`completed`、`in_progress`、`on_hold`。标记接口创建视频记录，重复添加由后端拒绝，不覆盖已有记录；当前模型没有独立收藏字段。

自动进度只针对已存在的视频记录，在进入视频和切换分 P 时触发，不持续监听播放器秒级进度。未配置 Token、未标记或查询失败时不写入。

标记查询使用 `GET /api/b-video/by-bvid?bvid=...`，由后端按当前账号和大小写精确匹配的 BV 号返回一条记录，未标记返回 `data: null`。后端需提供该接口；插件不再分页扫描视频列表，也不缓存“未标记”结果。

### 豆瓣手动采集

打开书籍或影视详情页，点击插件采集按钮，在独立录入页核对元数据、状态、进度和备注，预览查重后保存。已有记录只提交明确修改的字段；版本冲突后重新预览并合并本地修改。豆瓣公共评分不作为个人评分。

### 豆瓣标记自动同步

开关默认关闭。在插件中开启并授权 `movie.douban.com` 后，对当前及后续打开的电影／剧集详情页生效；书籍、搜索页及列表页仍使用手动采集。

- 只有豆瓣个人标记区域确认更新且表单关闭，才同步“想看”或“看过”。初始历史状态、仅打开表单、取消或保存失败不触发写入。
- 取消豆瓣收藏并确认成功后，会逻辑删除对应 AIO Life 观影记录。已有记录的状态更新保留备注、个人评分和其他元数据。
- 每个条目按顺序同步。失败或网络结果不确定时保留原请求键并暂停队列；先去 AIO Life 核实，再点击“核实后使用原请求重试”或“核实后清除待处理同步”。清除只影响本地队列，不修改业务记录；超过 24 小时不能重发原请求。
- 关闭开关停止后续检测与发送；服务地址或 Token 切换后隔离原账号队列。

### 购物商品录入与编辑

打开已登录的订单详情页并采集，核对订单 ID、商品 ID、名称、规格、数量、实付和购买日期。至少选择一件商品的“创建设备”或“加入衣柜”，再点击“确认保存”；未选择的商品不创建物品。

- **金额与日期**：行实付是整行全部数量的合计，标价不能替代实付。运费和优惠可按金额权重分摊，无权重时均分，需人工确认。购买日期优先使用付款日期，其次为下单日期；退款、预售和合并支付需核对实际金额。
- **多件与查重**：同款多件可分别选择归属。服务端按当前账号、平台、订单 ID、商品 ID 及已有数量查重，返回已有物品并创建缺少的数量，不覆盖已编辑字段；订单 ID 和商品 ID 必填且保持字符串。明细行和件序号只用于当前页面映射，重新采集不保证对应原规格行或第几件；历史未知来源记录不自动关联，逻辑删除后可重新录入。
- **封面**：订单图与商品主图在同一列表展示，点击缩略图上传。京东主图首次使用需授权 `item.jd.com`，优先读取已打开的商品页，否则临时在后台打开商品页并在结束后关闭。登录或安全验证导致读取失败时，打开商品页处理后重试，也可上传本地图片或无图保存。
- **保存后编辑**：按原物品 ID 读取最新记录，可修改名称、分类、状态、备注及封面等适用字段；不能切换设备／衣柜归属。同字段被其他页面修改时要求重新读取，部分失败可在当前页面重试失败项。
- **未保存内容**：只在当前页面内存中保留，刷新或关闭即丢弃；关闭工具栏弹窗不影响已打开的录入页。保存后的页面链接仅保留账号指纹、物品类型与 ID，刷新会从服务器读取。
- **结果不确定**：超时或提交中断后先核对设备／衣柜中的结果，不自动重发。当前页面保留相同内容的原请求键，可在 24 小时保护期内人工重试；提交中刷新或关闭后不恢复请求。请求重放保护与服务端来源查重是两个机制。

## 权限与数据

权限声明以 [manifest.json](manifest.json) 为准：

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存连接配置、Token、豆瓣自动同步开关及待处理队列 |
| `activeTab`、`scripting` | 用户发起采集时读取当前页面；注入已授权的功能脚本 |
| 固定站点权限 | B 站视频页、视频元数据 API，以及默认 AIO Life 服务 |
| 可选 HTTP(S) 站点权限 | 按实际操作授权自定义 API 服务、豆瓣自动同步、京东商品页及图片域名 |

Token 保存在扩展本地存储，由后台发起请求；网页内容脚本不能读取 Token，录入页不会取回 Token 明文。手动采集内容经后台内存一次性交接，交接标识 60 秒失效，不保存本地草稿；切换服务或账号后原录入页不可继续提交。豆瓣自动同步的待处理队列单独保存在扩展本地存储中。

采集只提交所需结构化字段，不上传 Cookie、收货地址、手机号或整页 HTML；来源链接清理京东 `PassKey` 等无关参数。自动图片读取限制为豆瓣、京东、阿里图片域名，拒绝重定向；上传支持 10 MB 以内的 PNG、JPEG、WebP、GIF。

## 开发与验证

本地测试使用 Node.js >=18 和 npm，依赖锁定在 [package-lock.json](package-lock.json)。在本仓库执行：

```bash
npm ci
npm test
```

`npm test` 使用 Node 测试运行器和 jsdom，覆盖页面解析、金额计算、账号隔离、业务成功码、请求重试、来源查重、编辑流程、豆瓣标记检测与 B 站行为等。Fixture 使用合成信息，不含个人订单或 Token。接口成功要求 HTTP 成功和整数 `code === 0`；ID 按字符串处理。

### 手动录入测试页

```bash
npm run test:harness
```

访问 `http://127.0.0.1:48763/`，默认使用模拟 API 和合成购物数据；`/?kind=douban` 切换为豆瓣数据。此测试页不模拟图片上传。连接隔离测试后端时：

```bash
CAPTURE_API_BASE=http://127.0.0.1:45688/api \
CAPTURE_TEST_TOKEN='<TEST_ACCOUNT_TOKEN>' \
CAPTURE_UI_PORT=48764 npm run test:harness
```

此模式会真实调用采集 API、创建或更新测试数据；已保存设备／衣物的编辑写入需要使用真实扩展，测试页只支持读取。Token 留在本地测试服务端，使用专用测试账号和数据库。`tests/chrome-shim.js` 仅由测试服务注入，不进入正式扩展。

### 豆瓣自动同步测试页

```bash
CAPTURE_API_BASE=http://127.0.0.1:45688/api \
CAPTURE_TEST_TOKEN='<TEST_ACCOUNT_TOKEN>' \
node tests/native-harness.js
```

访问 `http://127.0.0.1:48765/`。此入口使用合成 DOM、正式检测器与后台脚本，直接调用隔离 API，没有模拟成功模式；可验证打开／取消表单、想看、看过、失败及删除后的整页刷新。支持 `CAPTURE_TEST_AUTH_FILE` 指定本地测试凭据 JSON，`NATIVE_SUBJECT_ID` 指定测试条目，`NATIVE_UI_PORT` 修改端口。凭据文件不得提交。

单元测试、合成页面联调、真实网站 DOM 检查与已安装扩展的实站端到端验证需分别记录；测试通过不代表扩展已发布或后端已部署。2026-10-27 的旧草稿恢复行为已被移除，不能作为当前版本验收依据。

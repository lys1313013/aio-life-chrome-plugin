# AIO Life 浏览器助手

保留 B 站视频标记与进度入口，新增豆瓣书影音入库、影视详情页原生标记自动同步和京东／淘宝商品录入。购物功能直接创建设备或衣物；豆瓣直接保存到阅读、观影模块。订阅采集暂不包含在本版。

## 使用

1. 后端部署支持 `/api/capture/*` 的版本。功能复用现有阅读、观影、设备、衣柜表，不需要新增业务表或执行数据库结构迁移。
2. 在 Chromium 系浏览器的扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，选择本目录。运行时无需安装 npm 依赖或构建。
3. 点击工具栏中的 AIO Life，在连接设置填写 API 服务地址（包含 `/api`）和已有账号的 Authorization Token，允许访问该服务域名。Token 留空保留原配置，清除按钮可移除旧 Token。
4. 打开豆瓣书籍／影视详情页，或京东／淘宝已登录的订单详情页，点击插件采集按钮。预览表单在独立扩展标签页打开，关闭弹窗不丢草稿。
5. 豆瓣：核对标题、封面、作者／导演、状态、进度和备注，预览查重后确认保存。
6. 购物：核对名称、规格、数量、实付与购买日期，逐件选择“创建设备”或“加入衣柜”，至少选一件，直接点击“确认保存”；保存时校验商品数据，无需额外勾选或单独检查。未选择的商品不创建物品。
7. 购物封面将订单图与商品主图放在同一列表直接展示，点击缩略图即可上传；京东已授权时自动读取商品主图，首次未授权时点击“允许读取商品图片”。若未读取到，可打开商品页完成加载或登录后重试。也可上传本地图片或无图保存；豆瓣仍支持使用来源图片。成功页显示生成的设备／衣物 ID，锁定重复创建；保存后或重新打开已保存草稿时，自动读取原物品并直接进入编辑，可调整名称、分类、状态、备注及封面，再点“保存修改”更新原物品。读取失败时显示“重试读取物品”，不再保留看似可编辑的锁定表单。

## 豆瓣原生标记自动同步

在插件中打开“豆瓣标记自动同步”，首次需允许访问 `movie.douban.com`。默认关闭；开启后对当前和后续打开的**电影／剧集详情页**生效，想看、看过和取消收藏均无需逐条打开插件确认。书籍、Top250／搜索列表等入口不属于此自动同步范围，仍可使用主动采集。

- 在豆瓣保存“想看”或“看过”后，确认个人标记区域已更新且表单关闭，才同步到 AIO Life。打开弹窗、取消、保存失败、页面初始历史状态都不触发写入；同状态保存需要个人标记节点被替换的成功证据。
- 取消豆瓣收藏后同步移除对应观影记录。删除按钮产生短时本地意图；若豆瓣刷新整页，需要同条目、已登录页面恢复未标记按钮，才确认移除。仅点击删除或取消确认不会删除 AIO Life 记录。
- 已有观影记录只调整状态、当前进度和完成时间，保留备注、个人评分和其他元数据；无记录则创建。取消收藏采用现有观影逻辑删除，不增加业务表。
- 页面右下角显示实际同步结果。每个条目按操作顺序处理；失败或网络不确定时保留原请求键，后续操作排队，不自动重试或跳过。服务／Token 切换隔离队列，旧页面延迟操作不能发送到新账号。
- 先去 AIO Life 核对结果，再点击“核实后使用原请求重试”。超过 24 小时不重发；也可点击“核实后清除待处理同步”，此按钮只清除当前账号和条目的本地队列，不新增或删除业务数据。之后需要重新在豆瓣保存或取消标记。
- 关闭开关停止后续检测与发送。网页脚本无权使用通用 API 代理，也不能读取 Token；自动通道只接收同一豆瓣电影详情页顶层脚本的限定事件，不传短评、豆瓣评分、昵称或 Cookie。

## 行为规则

- **B 站视频标记**：待看、已看、学习中、暂停分别发送 `not_started`、`completed`、`in_progress`、`on_hold`；弹窗与视频页菜单保持一致。当前模型没有独立收藏字段。标记接口只创建记录，重复添加显示后端错误，不覆盖原记录；派生进度仅用于本地提示，不写入请求。
- **豆瓣已有记录**：保留已有进度和备注。更新只发送用户修改的字段；版本冲突后重新预览，用服务端最新字段合并本地修改。更换来源条目打开独立草稿，不携带旧记录 ID、进度或备注。豆瓣公共评分不作为个人评分。
- **购物录入**：不保存采购订单或商品历史、不创建或关联支出，也没有订单历史补录。商品明细标识只用于本次提交中匹配商品与生成的物品，不是永久去重标识。
- **金额与日期**：实付和标价分开，付款时间和下单时间分开；没有识别到的字段留空。行实付是整行全部数量的合计，合计等于整单实付。可显式按已有金额权重分摊运费和优惠，精确到分；无权重时均分，须人工确认。购买日期优先使用付款日期，没有时使用下单日期。退款、预售、合并支付等情况应手动确认实际物品价格。
- **同款多件**：数量为 2 时分别选择两件的目标类型，可以保存两件独立物品。只选一件就只创建一件。
- **短期重试保护**：后端使用现有 Redis 暂存同一请求的结果 24 小时。同一草稿、同一提交内容在此期间可使用原请求键手动重试；这不是永久商品去重，也不保证清除草稿、重新采集或跨浏览器操作不产生重复。
- **结果不确定**：请求超时、页面在提交中关闭，或后端提示结果待确认时，保留原请求键和内容，先到阅读／观影／设备／衣柜核实，不自动重试写入。超过 24 小时不直接重发原请求。保存成功但短期结果缓存未确认时仍展示已生成 ID 和明确提示，禁止再次创建。
- **再次采集**：已保存草稿禁用重复创建；保存后编辑按原物品 ID 更新，不重新创建，也不改变设备／衣柜归属。修改前读取当前记录，只提交编辑字段；若同字段已被其他页面修改则提示重新读取，失败的修改保留供核实后重试。若需要清除草稿重新采集，先确认现有设备／衣物，避免重复创建。
- **接口成功**：同时要求 HTTP 成功和整数 `code === 0`，并检查返回的业务记录 ID。

## 权限与隐私

- 手动采集通过 `activeTab + scripting` 读取当前页面；豆瓣自动标记仅在开关启用并授权后驻留详情页，输出必要的结构化字段；不上传 Cookie、收货地址、手机号或整页 HTML。
- Token 由扩展后台读取；网页内容脚本无法读取本地存储中的 Token，录入页不会取回 Token 明文。
- 草稿按服务、授权账号指纹、来源页面隔离。切换服务或 Token 后需重新采集；旧草稿不发送到新账号。
- API 服务及图片域名在使用时申请权限。京东商品主图按需申请 `item.jd.com` 权限，优先读取对应已打开商品页的主图，否则使用浏览器当前京东会话在后台临时打开商品页等待动态主图加载，完成或失败后关闭插件创建的临时页；后台短暂复用已读到的主图，避免刷新草稿反复请求；只返回主图链接，不读取推荐商品图片。自动图片读取只允许豆瓣、京东、阿里图片域名，拒绝重定向，流式限制 10 MB。失败可手动上传 PNG/JPEG/WebP/GIF，或无图保存。
- 来源链接移除京东 `PassKey` 等无关参数。草稿存放在当前浏览器，完成后可清除。
- B 站内容脚本只在进入视频或切换分 P 时同步已有记录的观看进度，不自动创建未标记视频。

## 开发与验证

```bash
npm ci
npm test
npm run test:harness
```

`npm test` 包含豆瓣原生成功确认、首次隐藏字段、删除导航意图、后台串行、账号隔离、同键重试和本地清除，以及解析器、精确金额、响应成功码、账号隔离、后台消息权限、原有 B 站回归、豆瓣并发修改、直接创建物品、超时手动重试与成功后锁定等测试。Fixture 使用合成信息，不含个人订单或 Token。

`test:harness` 在 `http://127.0.0.1:48763/` 提供真实录入页和测试用 Chrome API shim。默认 mock 后端和合成购物草稿；`/?kind=douban` 为豆瓣合成草稿，可直接在 Codex 右侧浏览器查看。

连接隔离的真实测试后端：

```bash
CAPTURE_API_BASE=http://127.0.0.1:45688/api \
CAPTURE_TEST_TOKEN='<TEST_ACCOUNT_TOKEN>' \
CAPTURE_UI_PORT=48764 npm run test:harness
```

Token 仅在测试服务端持有；代理只接受同源 JSON POST。只使用专用测试账号与数据库，mock 与真实服务使用不同端口隔离草稿。`tests/chrome-shim.js` 仅由测试服务注入，不在正式扩展中加载。

自动标记合成测试独立使用真实隔离 API，不提供假的成功响应：

```bash
CAPTURE_API_BASE=http://127.0.0.1:45688/api \
CAPTURE_TEST_TOKEN='<TEST_ACCOUNT_TOKEN>' \
node tests/native-harness.js
```

打开 `http://127.0.0.1:48765/`，可测试打开／取消表单、首次想看、修改看过、模拟失败及删除后的整页刷新。此页面明确标注合成 DOM，使用同份正式检测器与后台代码；只有 Chrome 扩展运行环境由测试 host 模拟，写入请求和响应来自真实后端。也可通过 `CAPTURE_TEST_AUTH_FILE` 指向本地测试凭据 JSON，Token 不进入浏览器或仓库。默认合成条目 ID 为 `99000036445098`，可用 `NATIVE_SUBJECT_ID` 指定独立条目；`NATIVE_UI_PORT` 可改测试端口。

## 文件

- `popup.*`：工具栏弹窗、现有 B 站入口、连接设置、主动采集。
- `capture.html`、`capture.css`、`capture/ui.js`：独立预览和编辑页。
- `capture/adapters/`：豆瓣、京东、淘宝 DOM 适配器。
- `capture/background.js`：后台凭据、限定 API 通信、图片读取上传。
- `douban-auto/`：原生标记成功检测、专用后台通道、顺序队列和页面反馈。
- `capture/core.js`：来源识别、精确金额、请求指纹、商品数据校验。
- `tests/`：合成 fixture、自动测试、本地可视化测试服务。
